# Darul Amin Ideal Madrasah – ডেমো ওয়েবসাইট

মাল্টি-ব্রাঞ্চ মাদ্রাসা ম্যানেজমেন্ট সিস্টেমের ক্লিক-করে-দেখার ডেমো। শুধু HTML/CSS/JS, কোনো সার্ভার বা ডেটাবেস লাগে না। সব ডেটা ব্রাউজারের localStorage-এ সেভ হয়।

## Netlify-তে ডিপ্লয়
1. এই ফোল্ডারের সব ফাইল একটি GitHub রিপোজিটরিতে আপলোড করুন।
2. Netlify > Add new site > Import from Git > রিপো বেছে নিন।
3. Build command ফাঁকা রাখুন, Publish directory `.` (netlify.toml-এ দেওয়া আছে)। Deploy চাপুন।

## ডেমো লগইন (Administration বাটন)
| ভূমিকা | ইউজারনেম | পাসওয়ার্ড |
|---|---|---|
| মূল অ্যাডমিন | admin | admin123 |
| কো-অর্ডিনেটর | coord1 | 1234 |
| হিসাব কর্মকর্তা | acct1 | 1234 |

শিক্ষার্থী পরীক্ষার জন্য: আইডি `S001`, রোল `1`, ক্লাস `৫`।

## ডেমোতে যা আছে
- হোমে ১:১ শাখা কার্ড, শাখার মেন্যু (Notice, Admission, Result, Gallery, Administration, Contact, Student Login)
- মূল অ্যাডমিন: শাখা দেখা (শুধু পড়া), নতুন ব্রাঞ্চ, স্টাফ আইডি তৈরি
- কো-অর্ডিনেটর: নোটিশ, শিক্ষার্থী (সফট ডিলিট, ফিল্টার, প্রিন্ট), ভর্তি অনুমোদন, রিলোড ছাড়া রেজাল্ট এন্ট্রি
- হিসাব কর্মকর্তা: ফি কার্ট ও প্রিন্ট রিসিট, অন্যান্য আয়, ডায়নামিক ফি/ব্যয় খাত, মাসিক আয়-ব্যয় রিপোর্ট

## ডেমোতে যা নেই (ফুল ভার্সনে যোগ হবে)
Node.js + MongoDB ব্যাকএন্ড, আসল লগইন নিরাপত্তা, ছবি আপলোড ও অটো রিসাইজ, PDF/Excel এক্সপোর্ট (এখন ব্রাউজারের Print > Save as PDF), শিক্ষক বায়োডাটা ও শিক্ষক লগইন, ক্লাস/পরীক্ষার রুটিন, শিক্ষক বেতন রিসিট, Excel রেজাল্ট আপলোড।

> সতর্কতা: এই ডেমোর পাসওয়ার্ড কোডেই দেখা যায়। আসল তথ্য কখনো এতে রাখবেন না।
